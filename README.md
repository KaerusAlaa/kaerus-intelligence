# Kaerus Intelligence

**Status: in development.** There is no working tool yet. For now this
repository only holds the scope, the planned sources and the roadmap. I will
update this page as things get built.

## What it is

An open-source project that follows how AI is changing drug regulation in
oncology: marketing authorisations, clinical trials, and the guidance that
regulators such as the EMA and the FDA publish on AI/ML.

## Why

Information on AI in drug development is spread across many sources and is
not easy to follow, especially in oncology. The idea is to collect public
sources, summarise them in a readable way, and then look at the trends across
them.

## Two parts

1. **Monitoring.** Collect public sources and produce short summaries.
2. **Analysis.** Look across items over time: which AI use cases reach
   regulators in oncology, and which questions keep coming back.

## Planned sources

All public: EMA (EPARs, guidance), FDA (guidance), ClinicalTrials.gov, PubMed.

## Roadmap

1. First prototype on a single source: oncology trials on ClinicalTrials.gov
   (Python, public API).
2. Add EMA and FDA documents.
3. First trend analysis on several weeks of collected data.
4. Documentation, licence and a clean first release.
